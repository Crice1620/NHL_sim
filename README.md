# 🏒 NHL Simulator & Magic Numbers Hub

An interactive web application built with **R Shiny** that simulates NHL slates, tracks magic numbers, and models team performance metrics using predictive analytics.

🔗 **Live Application:** [crice1620.shinyapps.io/NHL_Magic_Numbers](https://crice1620.shinyapps.io/NHL_Magic_Numbers/)

---

## 🌟 Application Features

* **Slate & Game Simulations:** Run automated and custom match simulations across NHL schedules to project series outcomes and game probabilities.
* **Magic Numbers & Standings:** Track elimination thresholds, playoff tracking metrics, and dynamic conference/division standings.
* **Team Performance Metrics:** Inspect advanced statistics, team DNA breakdowns, and specialized data inputs.

---

## 🛠️ Built With

* **Frontend/UI:** R Shiny, custom CSS styling
* **Data Processing & Simulation:** `tidyverse`, custom R scripting pipelines, dynamic HTML data tables
